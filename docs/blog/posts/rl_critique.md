# Some critical comments on the use of reinforcement learning models in neuroscience

In no particular order:
<!-- more -->
1. Reinforcement learning algorithms were developed by computer scientists who took inspirations from the animal behavior literature. But they lack any deep connection to actual animals, brains, or biology in that nothing about them turns on biological facts. This should make neuroscientists suspicious of the idea that the brain implements such a theory. Many purported examples of connection between reinforcement learning and neurobiology (e.g. the reward prediction error encoded by VTA dopaminergic neurons) are not strong enough to determine the RL algorithm supposedly being implemented. 
2. RL is an "as-if" model, akin to expected utility theory (EUT) in economics: it assumes that animals behave as if they are maximizing the expectation of time-discounted rewards, just as EUT assumes that humans act as if they are maximizing their utility functions. Consequently many of the usual criticisms of EUT also apply to RL. In some sense, RL faces even more serious problems; for example, we don't even have a good sense of basic concepts like reward (e.g. exploration itself could be rewarding). There are some versions of RL models in which realism is injected to improve fits on the observed data, often by degrading the models. But there is no principled way to do this, and as a result we get a hodgepodge of rationality and irrationality (e.g. introduce a bias term to degrade performance, but otherwise update the model optimally with gradient ascent). 
3. As a result, RL is silent on how such an algorithm can be implemented in the brain. In fact many RL researchers (like most machine learning researchers today) don't care about biological plausibility - RL simply posits some optimality condition, and specifies an iterative way to reach it. This approach has been wildly successful in domains where performance is key, such as building artificial systems that excel at board games. But neuroscientists seek mechanisms, not just performance. 
4. Given that the goal of (systems) neuroscience is to bridge the gap between single neurons (which are dumb) and behaviors (which are often intelligent), this makes reinforcement learning by itself not very useful. Take the example of a baseball player catching a fly ball. one could build an agent that recapitulates this behavior by solving differential equations given the initial velocity and launch angle of the baseball. But such a model would be irrelevant for trying to understand how the brain of the baseball player solves this complex sensorimotor task. I claim that RL models are in the same class as this model (despite the important difference that RL models can "learn"). Why not directly study the actual neural processes that lead to the behavior, rather than resorting to something that only behaves similarly?
5. RL simply doesn't work very well in the real world. It is about risk-controlled environment where probabilistic calculus can be used formulate an optimal solution - whereas the real world has a great deal of uncertainty - full of "unknown unknowns" where probabilistic calculus simply is not possible because it is either computationally intractable or the environment changes too frequently. On the other hand, biological organisms are built to deal intelligently with uncertainty rather than with risk. This might explains why RL agents usually learn very slowly what is learned very quickly by animals. 
6. RL is not very intelligent. It essentially tries to learn the best policy, which is nothing more than a lookup table that specifies what to do when in a particular state (probabilistically) given some information. But there is nothing intelligent about lookup tables - they just hold data. There are of course versions of reinforcement learning that uses a model rather than a lookup table, but the difference is superficial; it's just a matter of whether the function that maps external input to something that RL algorithm needs (e.g. action value or probabilities) is a function estimated by a neural network or a table (in this case, I would argue that what is truly interesting is neural implementation of that function rather than how it is used to guide behavior). Perhaps the most intelligent thing in RL is the learning rule which efficiently updates the lookup table until it converges to the optimal one (or gets close to it). But it is implausible to expect that the brain implements the most frequently used learning rules (e.g. gradient ascent). Some models require learning a very complex value function, or storing data for an intractably large number of states. 
7. Animals can learn to do quite complex things without any reinforcement (positive or negative). Tolman's classic paper describes numerous examples. One could argue reinforcement learning comes into play only to decide what to do (and not how to do it) but in that case it becomes toothless. 
8. In fact, almost nothing is learned through reinforcement; when was the last time you learned something through reinforcement learning?
9.  as skinner pointed out, reinforcement learning suggests that mistakes are useless; in some algorithms, no reward means no update; on the other hand, mistakes are essential for learning as empircially demonstrated

# Contradictions in neuroscience today
- we try to record from as many neurons as possible but we reduce their dimensionality
- we go at great lengths to distinguish the cell type, and yet use models that assume every neruon is the same
- we specifiy models of rationality (e.g. in reinforcement learning) and degrade it with parameters that reflect irrationality (we update it rationally, though)

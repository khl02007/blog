# Neuroscience doesn't need causality
...Of course it needs causality.
<!-- more -->
I won't go as far to deny the importance of causal factros, so this is a clickbaity title
but hwat i have issues with is the naive notion of causality, which is always on the other side of the dichomoty of 'yes the neural activity is acorrelated but is it causal?'
simply showing the activating the neuron causes behavior doesn't really tell us much about how this happens because it doesn't tell us much about what is going on
if we combine this with multiple streams of information then maybe we can learn a bit more but still doesn't tell us the mechanism
plus it is somewhat expected; of course brain causes behavior, so activing some node in the brain causes some behavior;
in general one would expect there to be many such nodes; it becomes more interesting if you can show that this is the only such node, but this is pretty much impossible, and even if you could do this it would just show that there is a bottleneck rather than 
what it really needs is a richer set of symbols, or a way to define a richer set of interactions and relationships than simple correlations
what it needs is more complex representations than simple correspondence to some world varaible or paramter of model
